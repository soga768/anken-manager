# 案件管理アプリ

案件と顧客を管理するWebアプリです。Spring Bootの学習を目的に、登録・一覧・編集・削除(CRUD)から、顧客との紐づけ、ログイン機能、テストまでを一通り作りました。

## 主な機能

- 案件の一覧表示・新規登録・編集・削除
- 顧客テーブルを分け、案件と外部キーで紐づけ(案件の登録・編集時に顧客をプルダウンで選択)
- ログイン・ログアウト(Spring Security)
- Repositoryのテスト(JUnit)

## 使用技術

- Java 21
- Spring Boot 4.1.1
- Spring Data JPA
- Spring Security
- Thymeleaf
- H2 Database(インメモリ)
- JUnit 5
- Maven

## 起動方法

1. このリポジトリをクローンします。
2. プロジェクトのフォルダで、次のコマンドを実行します。

```
./mvnw spring-boot:run
```

3. ブラウザで `http://localhost:8080/ankens` を開きます。
4. ログイン画面が表示されたら、下記のデモ用アカウントでログインします。

## デモ用アカウント

| ユーザー名 | パスワード |
| --- | --- |
| admin | password |

※ 学習用のデモアカウントです。パスワードはBCryptでハッシュ化して保存しています。

## 設計のポイント

- **顧客と案件を別テーブルに分割**: 案件が顧客を参照する多対1の関係(`@ManyToOne`)にして、顧客名の表記ゆれを防げる構造にしました。
- **パスワードのハッシュ化**: 平文では保存せず、BCryptでハッシュ化しています。
- **起動時のデータ投入を分離**: テスト用データの登録処理を専用クラスに切り出し、Repositoryのテストに影響しないようにしました。

## 注意事項

- DBはH2のインメモリを使っているため、アプリを停止するとデータは消えます。起動のたびにテスト用のデータが自動で登録されます。
